# Security Policy

## Supported Versions
This project is under active personal development. Only the latest commit on `main` is supported — there are no maintained release branches.

## Reporting a Vulnerability
If you find a security issue, please open a GitHub Security Advisory (Security tab → "Report a vulnerability") rather than a public issue, so it isn't disclosed before a fix is available. 
I'll do my best to respond within a few days — this is a personal project maintained in my spare time, so please be patient
